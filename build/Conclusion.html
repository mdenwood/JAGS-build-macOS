Here are some suggested Terminal commands to get started with JAGS for macOS:

  • Add /opt/jags/bin to your PATH:
    echo 'export PATH="/opt/jags/bin:$PATH"' >> ~/.zshrc
  • Launch the active build of JAGS:
    jags
  • List available JAGS builds:
    jags-version -l
  • View the help file for jags-version:
    man jags-version
  • View the help file for jags-uninstall:
    man jags-uninstall
  • View the help file for JAGS:
    man jags

Alternatively, you can install the rjags and/or runjags packages to interface JAGS directly to R.

If you encounter any issues with this installer, please post to the JAGS discussion forum
