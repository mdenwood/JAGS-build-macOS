JAGS for macOS

JAGS (Just Another Gibbs Sampler) is a program for analysis of Bayesian Graphical models by Gibbs Sampling written by Martyn Plummer, with contributions from Matt Denwood. The functionality of JAGS is based on the BUGS program created by the MRC Biostatistics Unit (http://www.mrc-bsu.cam.ac.uk). There is a short manual that describes the differences between JAGS and BUGS.

This package will install 64-bit universal (arm64 + x86_64) official builds of JAGS 5.0.0, built for binary compatibility with “Big Sur” and “Sonoma” releases of R for macOS (versions 4.3.0 and onwards), along with macOS-specific utilities that are designed to help manage multiple JAGS installations. This official binary is notarised/signed by Matt Denwood (the maintainer of macOS binaries of JAGS). The JAGS code has no dependencies on R and will work on its own.

Builds included:

The official macOS builds of JAGS 5.x and later install to /opt/jags, which is set up with subdirectories for different builds of JAGS along with symbolic links that allow a user to set the currently active version using the included utilities. You may wish to add /opt/jags/bin to your PATH so that the installed binaries and utilities (along with pkg-config files and man entries) are available from the command line.

The installer contains the following sub-packages:

  • JAGS utils - the jags-version and jags-uninstall utilities, along with pkgconf-lite.
  • JAGS transition - symlinks under /usr/local that allow compiling against JAGS 5.x in the same way as for JAGS 4.x, as well as allowing the CRAN build of rjags 4.x to work with the JAGS-4.3.2-vecLib-single-universal build. Note that this also removes any existing versions of JAGS 4.x (and earlier).
  • JAGS-4.3.2-vecLib-single-universal - the previous JAGS 4.3.2 release installed under the new /opt/jags directory.
  • JAGS-5.0.0-refBLAS-single-universal - a single-threaded build of JAGS statically compiled against Netlib's reference BLAS/LAPACK.
  • JAGS-5.0.0-vecLib-single-universal - a single-threaded build of JAGS compiled against Apple's Accelerate framework (vecLib).
  • JAGS-5.0.0-vecLib-gcd-universal - a multi-threaded build of JAGS using Apple's Grand Central Dispatch and Accelerate frameworks.

The standard installation includes all of the above, but it is possible to customise the installation via this installer. If multiple JAGS installations are selected, then preference is given to those lower in the list above - this can be altered after installation using the jags-version utility. To remove JAGS installations use the jags-uninstall utility.

System Requirements:

  • macOS 11.0 (Big Sur) or later
  • At least 50 MB of free disk space
  • Either a x86_64 (Intel) or arm64 (Apple silicon) processor

Important notes

• It is NOT necessary to re-install rjags version 5 if switching between builds of JAGS version 5.x, but switching between JAGS versions 4.x and 5.x will require re-installation of the appropriate version of rjags. Note that the CRAN builds of rjags_4-x are not compatible with any of the builds provided by this installer: see the JAGS discussion forum at https://sourceforge.net/p/mcmc-jags/discussion/610037/thread/115edca29d/ for more details. • If you interface JAGS and R using the rjags package (or other packages using the rjags interface), then it is extremely important to ensure that your builds of R and JAGS are fully binary compatible. Official builds of JAGS are binary compatible with the “Big Sur” and “Sonoma” releases of R for macOS (version 4.3.0 and later), but NOT previous versions of R for macOS (version 4.2.x and earlier). • If your builds of R and JAGS are NOT binary compatible, then you may see unexpected crashes and segmentation faults when using rjags. This applies to mixing up official builds, as well as to using other builds of JAGS that may or may not be binary compatible with the official build of R. We therefore strongly recommend using the official build of JAGS corresponding to the official build of R that you have installed. • Before installation, a script will be run to remove any existing installation of JAGS either in /usr/local and/or in /opt/R/arm64 - this is necessary to avoid potential linkage problems with R. If you have also manually installed JAGS in another location (for example using homebrew) then it is strongly recommended to also remove these. • As part of the installation process, you will be asked to authenticate as an administrative user. The first user you create when setting up macOS has administrator privileges by default. • Once the installation is complete, you can safely delete the installer. Note that there is no GUI associated with JAGS, so you will not find anything in Applications after the installation. If you wish to test the JAGS installation you should open a terminal window (Applications/Utilities/Terminal) and type /opt/jags/bin/jags (type exit to leave JAGS again). • The rjags and runjags packages for current versions of R are available from CRAN for the previous release of JAGS 4.3.2. Version 5.x of JAGS requires version 5-x of the rjags package, which is not yet on CRAN. However, we have provided pre-built binaries of the rjags-4 and rjags-5 package for macOS that are compatible with the JAGS binaries provided in this installer: see the JAGS discussion forum at https://sourceforge.net/p/mcmc-jags/discussion/610037/thread/115edca29d/ for more details. • Source code for these packages and more information can be found at the JAGS website: http://mcmc-jags.sourceforge.net • This build is being provided to you “as is”, with no warranties or guarantees of any kind. Should you encounter any problems with this installer, please contact us through the JAGS discussion forum at https://sourceforge.net/p/mcmc-jags/discussion/610037/thread/115edca29d/ • WHEN SUPPLYING FEEDBACK: If the problem is a crash, bad code generation, incorrect error message etc., the most valuable information you can provide is full and complete instructions on how to reproduce the problem.
